# Reference photographs

Put the reference photographs of the real place in this folder: several photos of the street
the scene should look like (here, a street with a tram line), ideally ungraded camera photos at
different times of day, from the driver's position and from the sidewalk.

The photos are only used to judge the rendered result side by side (the capture tools and
image statistics compare renders against them). The app never loads them, and they are never
used as textures.

Everything in this folder except this file is ignored by git, because reference photos are
usually third-party images that may not be redistributed. Keep your own copies here locally.
